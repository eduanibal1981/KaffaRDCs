# Build assessment campaign mockups

- [Option 1 · Single page](01-single-page.png) groups the form into Audit structure, Campaign details, and Schedule.
- [Option 2 · Guided steps](02-guided-steps.png) puts structure selection, campaign details, and review on three separate screens.

Both mockups were made with the built-in ImageGen tool using the supplied Android screenshot. The names filled in on Option 2 are examples. If Option 2 is implemented, the Review screen's edit action for Details should also cover Cycle and Schedule.
