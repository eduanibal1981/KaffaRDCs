# Self-audit scoring mockups

Both designs start the scoring area immediately after the app bar and a compact row for Sections and answered count. The Info icon opens the assessment summary. These English mockups were made with the built-in ImageGen tool using the supplied Kafaa screenshot.

- [Option 1 · Compact checklist](01-compact-checklist.png) keeps multiple criteria visible and opens comments and evidence on demand. The second panel shows Assessment info and Review submission.
- [Option 2 · Focused scoring](02-focused-scoring.png) shows one criterion with larger scoring targets, Previous and Next controls, and a section navigator with an Unanswered filter.

The proposed combination is Option 1 with the Unanswered filter from Option 2. Review submission can link directly to unanswered criteria and required proof. Show pending uploads, save failures and conflicts where the user can act on them. For an untouched checklist, show No answers yet in place of a readiness grade. Preserve saved scoring options, thresholds, points and applicable N/A controls. The designs do not specify implementation or test results for Arabic, right-to-left, large text, offline or read-only states.
