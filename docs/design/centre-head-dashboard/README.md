# Head of Centre dashboard concepts

These four mobile mockups use the supplied Bousher screenshot as a reference for the page title, centre name, and existing navigation. Each picture shows the same layout with fictional sample data on the left and empty results on the right. The empty examples distinguish unavailable metrics from a known count of zero open actions.

1. [Audit spotlight](01-audit-spotlight.png): a full-width official audit card anchors the screen, with the other three cards stacked below.
2. [Compact overview](02-compact-overview.png): four equally weighted cards in a two-by-two grid.
3. [Action first](03-action-first.png): overdue work leads, followed by a compact digest of audit, self assessment, and satisfaction.
4. [Assessment pair](04-assessment-pair.png): the official audit and self assessment share a section, with satisfaction and actions below.

All four pictures were created with the built-in image generation tool. They are visual concepts; they do not change the Flutter app, scoring, or data. The pictures show English copy; Arabic, right-to-left layout, and large-text behavior have not been evaluated.
