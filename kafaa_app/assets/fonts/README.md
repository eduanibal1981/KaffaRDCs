# Cairo report fonts

Cairo Regular and Bold are bundled for Arabic and English PDF reports, including
sample exports without network access. Both are static instances of Google
Fonts' Cairo variable font, with slant 0 and weights 400 and 700.

Source and license are available from the Google Fonts Cairo directory. The
SIL Open Font License is included in OFL.txt.

https://github.com/google/fonts/tree/main/ofl/cairo
