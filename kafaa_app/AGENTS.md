# Kafaa Flutter workspace entry point

Read `../AGENTS.md` and `../MEMORY.md` before working in this directory. They
define this project's rules, account boundary, and verified state. This bridge
also applies when an editor opens `kafaa_app` as its working directory.

The only hosted database for this application is **kaffaDB**, project reference
`onzmwoajiyennqtjcjez`. KeepSims, PairCompass, and simSaveDB are unrelated.

Start Codex from the parent `Kafaa Project` workspace when using its dedicated
MCP configuration in `../.codex/config.toml`.
